مشروع عيد ميلاد روان — تشغيل وتخصيص

الملفات:
- index.html: هيكل الموقع.
- style.css: التصميم والألوان والتجاوب مع الموبايل.
- script.js: محطات القصة، معرض الصور، الرسالة، والمفاجآت.

طريقة التشغيل:
1. فك ضغط الملف ZIP في مجلد.
2. افتح مجلد rowan-birthday.
3. افتح index.html في Chrome أو أي متصفح حديث.
4. يلزم اتصال بالإنترنت لتحميل الخطوط من Google Fonts، لكن بقية التصميم والوظائف تعمل محليًا.

تخصيص الصور:
- ضع صورة الغلاف باسم cover.jpg داخل assets/images/
- أضف صور الذكريات بالأسماء photo-01.jpg إلى photo-06.jpg داخل assets/images/
- لو الصور غير موجودة، ستظهر أماكن مخصصة بدلًا منها.
- الأفضل استخدام صور مضغوطة بحجم مناسب للموبايل، واحصل على موافقة روان قبل مشاركة صور خاصة.

تخصيص القصة والرسالة:
- افتح script.js في محرر مثل Visual Studio Code.
- عدّل مصفوفة storyMoments لتغيير أسماء المحطات والتواريخ والوصف.
- عدّل مصفوفة galleryMoments لتغيير عناوين الصور والتعليقات.
- عدّل personalLetterText واكتب رسالتك الحقيقية واسمك في التوقيع.

الموسيقى:
- ضع ملف MP3 تملك حق استخدامه باسم music.mp3 داخل assets/audio/
- شغّل الموسيقى من الزر أعلى الموقع؛ لا تبدأ تلقائيًا.
- مجلد audio فارغ افتراضيًا لأن المشروع لا يتضمن موسيقى محمية بحقوق نشر.

ملاحظات:
- المشروع واجهة أمامية فقط؛ لا يحتاج قاعدة بيانات أو خادم.
- لرفع الموقع على الإنترنت وإرسال رابط لروان، استخدم خدمة استضافة صفحات ثابتة مثل GitHub Pages أو Netlify.
- لا ترفع صورًا أو معلومات خاصة إلا إذا كنت مرتاحًا لمشاركتها.
